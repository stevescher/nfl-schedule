Privacy Policy

Last updated: September 6, 2026

Overview

NFL Schedules is a free, static website. There are no accounts, no sign-up, and no personal information collected or stored on any server we operate. The site's only job is to show you a team's schedule and let you subscribe to or download a calendar file.

Data We Do Not Collect

We do not collect:

  • Names, email addresses, or any personally identifiable information
  • Location data
  • Payment or financial information
  • Cookies

This site does not use analytics, tracking scripts, or advertising of any kind.

Local Storage

This site does not use your browser's localStorage or cookies to store any preferences or data.

Calendar Subscriptions

Each team page links to a .ics calendar file that you can subscribe to (Apple/Outlook), add to Google Calendar, or download directly. Subscribing means your calendar app periodically re-fetches that file from this site to stay current. No personal data is included in the file or sent as part of that request beyond what your calendar app normally sends to any URL (e.g., its own user agent).

Hosting

This site is hosted on GitHub Pages. As the hosting provider, GitHub may log standard web server data such as IP addresses, request timestamps, and browser user agents as part of normal infrastructure operations. This is governed by GitHub's Privacy Statement.

Standings Data

Team win-loss records and division rank shown on team pages are sourced from ESPN's public standings API. This data is fetched by the site's build process, not from your browser, so no information about you is sent to ESPN when you view a page.

Third-Party Links

The “Buy me a coffee” link goes to buymeacoffee.com, which has its own terms and privacy policy. No data is shared with Buy Me a Coffee unless you choose to visit that site. The “Google Calendar” button opens Google's own calendar-add flow on google.com, governed by Google's privacy policy.

Children's Privacy

This site does not knowingly collect any personal information from children under 13, and is not directed at children.

Changes to This Policy

If this privacy policy changes materially, the “Last updated” date above will be updated. Continued use of the site after changes constitutes acceptance of the updated policy.

Contact

Questions about this policy, or a request regarding your data, can be sent via the GitHub repository's issue tracker.
